# Git Workflow

1. Create a feature branch from main.
2. Make the application or infrastructure change.
3. Run the local test suite.
4. Commit with a clear message.
5. Push the branch and create a pull request.
6. Review and merge into main.
7. Jenkins checks the merged commit and runs the CI/CD pipeline.

Example branches:
- main
- develop
- feature/inventory-crud
- feature/monitoring
- fix/pipeline
